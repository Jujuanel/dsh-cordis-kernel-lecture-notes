# Cordis 内核讲义

面向初学者的 DeepSeek Harness（DSH）Cordis 内核长讲义：从“什么是插件”讲起，一直讲到能自己编写 DSH 插件。共 25 章、6 个部分、3 个附录。

## 阅读

整份讲义是一个静态页面，直接用浏览器打开 `index.html` 即可，不需要构建。

页面会在浏览器本地记住阅读进度、上次阅读位置和书签，数据只保存在当前浏览器中。

| 快捷键 | 作用 |
| --- | --- |
| `B` | 在当前位置添加书签 |
| `[` / `]` | 跳到上一个 / 下一个书签 |
